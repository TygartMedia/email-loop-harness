# Example Flow (redacted)

**Day 1, 09:12** — Personal seat sends the intro thread:
Subject: `[Loop] <> Ops <> Build — capabilities intro`
Body: seat roles, lanes, the work-order rule, the no-auto-send rule.
This thread becomes the constitution. (Real one: 2026-09-09.)

**Day 1, 14:40** — Personal seat files WO-001 (tracker first), then emails:
Subject: `[Loop] WO-001 — publish the new pricing page`
Ops picks it up, hands the assets to Build on the same thread.
Build replies with the staging link + verification. Ops confirms.
Personal seat tells the human: "Pricing page staged, link's on the thread —
one tap and it goes live."

**Day 3** — A reply arrives on the WO-001 thread from Build at 02:14.
The 15-minute watcher catches it at 02:30, diffs the watermark, hands the
personal seat: "Build replied on WO-001 — deploy verified, needs your tap."
The human taps. Done.

**Day 5** — Someone sends a loop-adjacent email WITHOUT the token in the
subject. The watcher misses it. The human notices, the token gets added,
and the subject-line rule earns its scar tissue. (Real: three emails,
2026-09-11.)

That's the whole system. Threads for scope, the tracker for record,
the watcher for attention, the human for judgment.
